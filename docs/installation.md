# Installation

## Stable release

To install Project Prototype, run this command in your terminal:

```sh
uv add project-prototype
```

Or if you prefer to use `pip`:

```sh
pip install project-prototype
```

## From source

The source files for Project Prototype can be downloaded from the [Github repo](https://github.com/jonesmartins/project_prototype).

You can either clone the public repository:

```sh
git clone https://github.com/jonesmartins/project_prototype
```

Or download the [tarball](https://github.com/jonesmartins/project_prototype/tarball/main):

```sh
curl -OJL https://github.com/jonesmartins/project_prototype/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd project_prototype
uv sync
```
